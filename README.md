# VRChat Friends & Group Instance Viewer

**Version: 1.6.8**

VRChatのフレンドの居場所、Friend / Groupインスタンス、Favoriteワールド、通知をChromeで確認できる非公式拡張機能です。VRChat Inc.が制作・承認・提供するツールではありません。

- [Chrome Web Store](https://chromewebstore.google.com/detail/vrchat-friends-group-inst/pncejiodjgmlklhgkpclcplgacbohbla)
- [GitHub](https://github.com/mos-vrc/vrchat-friends-and-group-instance-viewer) / [Booth](https://booth.pm/ja/items/8921102)
- [更新履歴](CHANGELOG.md) / [プライバシー](PRIVACY.md) / [認証・通信仕様](SECURITY.md) / [対応環境と制約](VALIDATION.md)

## インストールと起動

Chrome Web Storeからインストールし、同じChromeでVRChat公式サイトへログインしてから拡張機能ボタンを押してください。専用の一覧ページが開きます。

手動で導入する場合は配布ZIPを展開し、`chrome://extensions`でデベロッパーモードを有効にして「パッケージ化されていない拡張機能を読み込む」からmanifest.jsonがあるフォルダを選択します。

## フレンドとインスタンス

- 左側一覧を名前・Favoriteリスト・Join Friendsで絞り込み、右側の「すべて」「Favorite+」「Favorite」「Group」でインスタンスを確認できます。「フレンド」ではユーザーごとの居場所を表示します。
- インスタンスは「フレンド順」「参加人数順」で並べ替えできます。フレンド表示順やOffline内の並び順はオプションで変更できます。
- 左側一覧の右端をドラッグして幅を調整できます。カードは小／中／大、シンプル／ノーマルを選択できます。ノーマル表示も複数段のフレンドを省略せず表示します。
- OtherPlatformとOfflineはフレンド一覧の右下の小さな矢印から設定の小窓を開き、チェックで表示します。小窓はフレンド一覧に重ねて表示し、右上の矢印・外側クリック・Escで閉じられます。設定欄は初期状態では閉じており、開閉状態とチェックの選択状態を保存します。最終アクティブ日時はブラウザのタイムゾーンで表示し、シンプルのOfflineカードでは日付と時刻を2行で表示します。日時が取得できない場合は不明と案内します。
- ユーザー画像が未設定・非対応・取得失敗の場合は、白黒の人物シルエットを表示します。
- ユーザーのFavoriteマークから登録・リスト移動・解除できます。登録先選択中は対象のマークとカードを強調します。リスト名は鉛筆から変更できます（20文字以内）。
- 一部の情報を取得できないカードには「一部取得失敗」と「再取得」を表示します。失敗した情報だけを取得し、同じカードでは更新1回につき手動3回までです。成功済みの情報は残します。
- InviteMeは対象インスタンスへの自分宛て招待を送ります。ユーザー画像から公式プロフィール、ワールド画像から公式ページを開けます。
- フレンド外のインスタンスオーナー表示は標準OFFです。ONの場合は点線枠・灰色Ownerタグで示します。現在の参加者とは限らず人数に加算しません。Favoriteタブでは表示しません。

## ワールド管理

上部の地球儀アイコンで開きます。

- 足跡（Recent）はVRChat APIから最近訪問したワールドを表示します。独自の訪問履歴・回数・訪問日時は記録しません。
- 通常／VRC+のFavoriteリストを確認し、登録・移動・解除・リスト名変更ができます。リストの可否と上限はアカウントに従い、VRC+未加入者に専用リストを表示しません。
- 未登録のマークは黒丸、登録済みは★1から始まるリスト番号です。内部タグと表示名を区別して操作します。
- カードは小／中／大に対応し、常にノーマル表示です。PC／Androidの対応環境、URLコピー、ワールド名・作者を表示します。取得済みのカードを先に表示し、Favorite確認中は状態を案内します。
- 情報取得不可のワールドはその旨とワールドIDを表示します。再登録できないワールドの移動は許可せず、解除後に復元できない場合があります。

## 通知

地球儀とオプションの間の封筒から小窓を開きます。現在の画面を維持し、外側クリック・Esc・閉じるボタンで閉じられます。取得中の案内は見出しの横に表示します。

- バッジは残っている表示対象の通知数です（100件以上は99+）。未読件数ではありません。開くとき・操作後・既存の更新時に取得し、独立した常時監視は行いません。
- フレンド申請は送信者の名前・画像を表示し、承認／拒否できます。Group等の承認／拒否はAPIが提示する操作に従います。
- Inviteは送信者の名前・アイコンを表示し、「参加先を開く」「既読にする」を使用できます。Inviteの返信機能はありません。招待リクエストは返信・現在地への招待など対応する操作を表示します。自分が送った通知には返信できません。
- Group通知に画像がない場合はグループアイコンを表示します。画面内の通知だけを補完し、ユーザー情報とGroup情報の取得を合わせて最大2並列に制限します。取得済みの情報と画像は共有キャッシュを利用します。
- 招待リクエストへの自由入力返信は最大64文字です。既存の同文枠を再利用し、必要な場合だけ変更可能なカスタム返信枠へ保存して送信します。保存した枠は約1時間再編集できません。デフォルト枠は上書きしません。
- 個別の既読は対象の通知を処理します。「すべて既読にする」は確認後に取得済み通知を順番に処理し、フレンド申請・Group招待・その他の承認待ちは除外します。途中停止は処理中の1件が終わってから反映します。独立した削除ボタンはありません。
- 通常通知は最大2000件、Group等は最大100件まで取得します。多い場合は一部表示の案内を出します。片方の取得失敗でも取得済みの情報を残します。
- エラーは短い案内とコピー機能で示します。送信結果が不明な場合は再送せず、読み取りによる状態確認または公式ページで確認してください。通常の通知本文・返信下書きはメモリ内だけに保持します。ピン留めした通知は下記の保存対象です。

Group通知はピン留めできます。ピン留め中は一覧上部に表示し、個別・一括の既読対象から外します。承認／拒否は使用できます。ピン留め時点の見出し・本文・Group名・通知日時・リンク・保存日時をアカウント別にブラウザ内へ保存します。最大160pxの静止サムネイルも保存します。原文の編集や消失で保存内容を更新・削除せず、消失後は「保存した通知」として表示し、既読操作や赤い通知件数には含めません。ピン解除で保存分を削除します。取得キャッシュ削除では保持しますが、拡張機能の削除・ブラウザ保存領域の消去では失われます。画像失敗時も本文は残し、保存容量不足は案内します。既存ピンは次回取得できた原文から移行し、消失済みの本文は復元できません。

「すべて既読にする」右側の開閉ボタンで最大200文字のメモを表示します（一部の絵文字は2文字分）。入力はアカウント別に自動保存し、キャッシュ削除でも保持します。全削除するとメモなしになります。通知が残っている間は赤い件数バッジ、通知0件でメモまたはピン留めした保存通知がある場合は緑の丸を表示します。メモ欄は固定高さで、文字数は入力欄内の右下に表示します。通知一覧だけをスクロールさせ、メモ展開用の余地をあらかじめ確保して下側に開きます。メモにリマインダー機能はありません。

## 右下のメモ帳

通知内のメモとは別に、右下の小窓へ最大200文字を入力できます。内容と開閉状態はアカウント別に自動保存します。閉じたときはメモアイコンを表示し、内容がある場合は緑丸を付けます。オプションの「右下にメモ帳機能を表示」で表示を切り替えられます。初期設定はオンです。キャッシュ削除でも内容を保持し、別の端末やブラウザへの同期は行いません。

## オプションと更新

- 最初は表示サイズ・表示形式・テーマ・自動更新の4項目を表示します。「さらに表示」で言語・並び順・オーナー表示・キャッシュ削除・診断コピーを展開できます。展開状態と設定は保存します。
- 言語は日本語／英語です。保存済みの選択を優先し、未設定の場合はブラウザの言語から選びます。地域や所在地による判定ではありません。
- テーマはライト／サンド／ミスト／アッシュ／ダークブルー／ダークの6種類です。初期テーマはアッシュで、保存済みの選択を優先します。
- 自動更新はなし／5分／10分／30分です。更新開始時刻を基準とし、非表示中・編集中・変更操作中は延期します。期限を過ぎた場合は戻ったとき・編集終了後に一度更新します。
- 更新日時は標準で経過時間を表示し、クリックで時刻表示に切り替えます。表示方式は保存し、正確な日時はtipsでも確認できます。日時はブラウザのタイムゾーンです。
- 左端の更新ボタンは現在の画面を再取得します。初回起動・更新開始・保存中・完了・失敗を文章で案内します。更新アイコンは回転しません。
- 右側一覧をスクロールすると「上部へ戻る」ボタンを表示します。
- 「キャッシュを削除」は表示設定を残して取得データを削除します。VRChat上のFavorite登録は解除しません。

「アイコンフレームを反映」は追加オプション内、オーナー表示の下にあります。標準OFFで、ONにすると取得済みのユーザーの設定に対応するフレームを画像に重ねます。共通一覧と画像キャッシュを再利用し、ユーザーごとの追加取得はしません。画面外・非表示・動きを減らす設定では静止画像を使用します。対応するフレーム情報がない場合は通常アイコンのままです。フレームは中央に配置し、表示枠からはみ出す外周の飾りは切り取ります。

## 診断情報と認証

診断コピーにはバージョン、表示設定、件数、定型化した処理・HTTP状態・エラー分類、Groupの概要・詳細取得済み・取得失敗・再取得中の件数と取得枠の使用状況を含めます。ID、名前、通知本文、返信文、画像URL、認証情報、APIエラー原文は含めません。クリックでクリップボードへコピーし、自動送信は行いません。

Chromeの既存VRChatログインセッションを使用します。認証Cookieやトークンを拡張機能が読み出し・保存する処理、開発者サーバーへの送信、広告やアクセス解析はありません。取得情報と画像の一部はブラウザ内にキャッシュします。通信・保存の詳細はSECURITY.mdとPRIVACY.mdをご覧ください。

API変更、混雑、公開範囲、アカウント権限により表示や操作ができない場合があります。対応環境と制約はVALIDATION.mdをご覧ください。

## English

An unofficial Chrome extension for VRChat friends, instances, Favorite worlds and notifications. Install from the Chrome Web Store, sign in to VRChat in the same Chrome browser, then click the extension icon. Japanese and English are supported; your saved choice takes priority over browser language. Dates use your browser time zone.

See PRIVACY.md and SECURITY.md for data handling, VALIDATION.md for requirements and limitations, and CHANGELOG.md for release notes.
