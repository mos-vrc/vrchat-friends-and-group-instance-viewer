# VRChat Friends & Group Instance Viewer

**Version: 1.6.5.18**

VRChatのフレンド、インスタンス、FavoriteワールドをChromeで一覧表示する非公式拡張機能です。

- [Chrome Web Store](https://chromewebstore.google.com/detail/vrchat-friends-group-inst/pncejiodjgmlklhgkpclcplgacbohbla)
- [ソースコード・配布](https://github.com/mos-vrc/vrchat-friends-and-group-instance-viewer)
- [プライバシー](PRIVACY.md) / [認証・通信仕様](SECURITY.md) / [更新履歴](CHANGELOG.md)

## インストール

Chrome Web Storeからインストールするか、通常版ZIPを展開してChromeの拡張機能画面で「デベロッパーモード」→「パッケージ化されていない拡張機能を読み込む」から展開先を選択してください。
VRChat公式サイトにログインした状態で、拡張機能ボタンを押すと専用ページが開きます。

## フレンドとインスタンス

- 左側のフレンド一覧を名前検索、Favoriteリスト、Join Friendsで絞り込みできます。
- 「すべて」「Favorite+」「Favorite」「Group」でインスタンスを表示。「フレンド」ではユーザーから居場所を確認できます。
- インスタンスの並び順は「フレンド順」「参加人数順」。フレンド表示順はFavorite List順または名前順です。
- 左側の一覧の右端をドラッグして幅を調整できます。
- OtherPlatformとOfflineは左下のチェックで表示します。Offlineの最終アクティブ日時はブラウザのタイムゾーンを使用します。
- ユーザーの★でFavoriteリストを変更できます。リスト名横の鉛筆で名前を編集できます（20文字以内）。
- インスタンスのワールド画像は中央基準で表示し、画像全体を暗くするフェードは使いません。ワールド名には背景付きのラベルを表示します。
- InviteMeは自分宛ての招待を送信します。ユーザーアイコン・ワールド画像から公式ページを開けます。
- 「フレンド外のインスタンスオーナーを表示」は初期値オフ。オンでは点線枠と灰色Ownerタグで表示します。現在の参加者とは限らず、人数には加算しません。フレンドと同じ配置の先頭に表示し、折り返したフレンドはオーナー枠の下にも並びます。Favoriteタブでは表示しません。

## ワールド管理

オプションの左にある地球儀アイコンで開きます。

- 「足跡 / Recent」に最近訪問したワールドを表示します。訪問日時・累計回数は表示しません。独自の訪問履歴は記録しません。
- 通常／VRC+のFavoriteリストを表示し、ワールドの登録・移動・解除、リスト名の変更ができます。VRC+の可否・上限はアカウントの権限に従います。未加入の場合、VRC+専用リストは表示しません。
- ワールド画像右上は、未登録なら黒丸、登録済みなら★1から始まるリスト番号です。表示名と内部タグは区別します。
- ワールド画像の左上にPC／Androidの対応環境、右下にURLコピーを表示します。画像下のワールド名と作者名は各1行で、長い名前は省略しtipsで全名を確認できます。ワールド管理は常にノーマル表示です。
- 取得不可のワールドは「情報取得不可」、作者欄にワールドIDを表示します。移動・再登録は行わず、解除のみ可能です。解除を元に戻せない場合があります。

## オプションと更新

- 日英切り替え。保存済みの指定がなければブラウザの言語から初期言語を選びます。
- 右側が400px以下の場合、インスタンスのワールド画像とユーザー欄を上下に配置してアイコンの欠けを防ぎます。
- 上部メニューは表示内容の幅に合わせて余白を縮め、収まらない場合だけ2段に整理します。極端に狭い幅では地球儀・設定を上段へ移し、更新日時は必要に応じて折り返します。タブのみ横スクロールし、狭い幅でもソート欄を引き伸ばさず更新日時を表示します。更新ボタンのtipsでも時刻を確認できます。
- フレンドカードは左揃えで6px間隔に配置します。ノーマルは小340px／中380px／大420px、シンプルは小218px／中248px／大288pxで揃え、表示領域が足りない場合だけ縮めます。
- フレンドのシンプル表示ではFavorite操作のtipsだけを表示します。ノーマル表示と左側一覧のtipsは維持し、Favoriteマーク上ではインスタンスプレビューを表示しません。
- 表示サイズ：小／中／大。インスタンスの表示形式：シンプル／ノーマル。フレンドのシンプル表示は四角い画像の下部に名前、左上にステータス、右上にFavoriteを表示します。
- テーマ：ライト／サンド／ミスト／アッシュ／ダークブルー／ダーク。
- 自動更新：なし／5分／10分／30分。非表示中に期限を迎えた場合は、再表示時に一度更新します。
- 左端の更新ボタンは現在の画面を再取得します。取得中は連打できません。429では少し待ってから再取得してください。
- 「キャッシュを削除」は表示設定を残して取得データを削除します。
- 保存結果が不明な変更は自動で再送しません。画面の案内に従い、公式ページや更新で結果を確認してください。

## 認証・通信と注意事項

VRChat公式サイトのログイン済みセッションを使います。auth Cookieを拡張機能が読み出し・保存する処理、開発者独自サーバーへのデータ送信はありません。
通常版はVRChatへのAPI・画像アクセスに必要な権限を使用します。詳細はSECURITY.mdをご覧ください。
取得データのキャッシュと表示設定はブラウザ内に保存されます。画像はアカウント別に再利用し、全体で64MiB・512件を上限に保存します。期限切れのワールド表示情報は先に表示して裏で更新します。API変更・アクセス権・ワールドの公開状態などにより情報を表示できない場合があります。
VRChat Inc.が制作・承認・提供するツールではありません。
